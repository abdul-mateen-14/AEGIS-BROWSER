Checking your version

To see exactly which build you are running, open Menu → Settings → About Aegis. The page shows the Aegis release number alongside the exact Chromium version Aegis was built from, and it is also where update checks happen.

If you want the raw engine details, open chrome://version. It lists the full user-agent string, the command line the browser was started with, the profile path and the build revision — handy when filing a bug or checking that a change you expect is actually present in your build.

Version numbers matter more for a privacy browser than for a mainstream one: the compiled Shield blocklist, the certificate root store and Chromium’s security fixes all update with each release. When About Aegis offers an update, let it finish and restart when prompted — staying current is the easiest protection there is.

If the version page fails to open or an update will not apply, use the feedback entry in the browser menu and include the version string from chrome://version.
