What is Aegis Browser?

Aegis Browser is Chromium, rebuilt with privacy switched on from the first launch. The rendering engine, site compatibility, extensions and developer tools are exactly what you know — the difference is everything that happens around the web content.

  • Shield network blocking. A compiled list of 92,957+ known ad and tracking hosts is refused at the network level, before any data leaves your device. Main-frame navigation is never blocked: the site itself always loads.
  • No Google services by default. No Google account sign-in in the browser UI, no Gemini integration, no Google-synced password storage, no usage metrics. Google sites themselves work normally as websites.
  • Google stays the default search engine. That is a deliberate choice, works without any account link, and can be changed anytime in Settings → Search engine.
  • End-to-end encrypted sync. Optional Aegis Sync with your Aegis ID encrypts data on your device before it leaves; the server stores only ciphertext.

Aegis is free and open source software — every patch that separates it from Chromium is inspectable in the project repository.
