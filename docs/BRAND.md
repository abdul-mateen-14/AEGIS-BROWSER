# Aegis Browser — Brand Kit

The single source of truth for Aegis visual identity. Everything here is
derived from the master logo supplied by the project owner
(`aegis/branding/logo/aegis-logo.png`, 2000×2000) and the chosen brand
typeface (Montserrat).

## 1. Logo

A sharp, geometric monogram: an abstract **"A" that reads as a shield**,
built from hard straight strokes with an arrow-like counterweight. Strictly
two-tone. Wordmark: `AEGIS BROWSER` (Montserrat, Bold, all caps) over the
tagline `YOUR ULTIMATE DIGITAL SHIELD` (Montserrat, Regular, all caps).

| Asset | File |
| --- | --- |
| Master logo (mark + wordmark, black) | `aegis/branding/logo/aegis-logo.png` |
| Traced launcher icon set | `aegis/branding/icons/res_chromium_base/` |
| Regeneration script | `scripts/branding/make_icons.py` |

Rules: never recolor the mark, never place it on a colored field, never
outline it, never rotate it. Clear space around the mark ≥ 25% of its width.

## 2. Palette

Sampled directly from the master logo (corner pixels: `rgb(7,7,7)`).

| Token | Hex | Use |
| --- | --- | --- |
| **Aegis Black** | `#070707` | Primary surfaces, icon background, dark theme base |
| **Aegis White** | `#FFFFFF` | The mark, primary text on dark, high-emphasis actions |
| Ink 800 | `#141416` | Raised dark surfaces (cards, sheets) |
| Ink 700 | `#1E1F22` | Secondary dark surfaces |
| Ink 500 | `#2A2A2E` | Borders / dividers on dark |
| Smoke 400 | `#9E9EA4` | Secondary text, muted icons |
| Smoke 200 | `#C9C9CE` | Disabled text, placeholders |

The brand is **deliberately monochrome**: no gradients, no gloss, no accent
hue. If a status color is unavoidable in UI (error/success), use platform
defaults — never introduce brand colors for them.

## 3. Typography

**Montserrat** (Google Fonts, SIL Open Font License — free for commercial
use, can be bundled into the app later).

| Role | Style |
| --- | --- |
| Wordmark | Montserrat Bold (700), ALL CAPS, letter-spacing ≈ +2% |
| Tagline / captions | Montserrat Regular (400), ALL CAPS, letter-spacing ≈ +8% |
| Headlines (future UI) | Montserrat SemiBold (600), sentence case |
| Body (future UI) | Montserrat Regular (400) |

Note: Chromium cannot download fonts at build time; bundling Montserrat for
in-app screens is a deliberate later step (the settings UI keeps platform
typography until then). Brand materials (icons, release graphics, website)
use Montserrat now.

## 4. Design language

1. **Geometric precision** — every shape reduces to straight lines and hard
   angles (45–60°), like the mark. No rounded blobs, no hand-drawn curves.
2. **Monochrome contrast** — one idea per surface: black OR white carries it.
   Depth comes from the ink ramp above, never from color.
3. **Dark-first** — the brand lives on `#070707`; light theme inverts to
   white with Aegis Black text.
4. **Shield semantics** — protective, quiet, confident: copy is short,
   declarative, no exclamation marks ("Your ultimate digital shield").
5. **Negative space** — when in doubt, remove. The mark itself is mostly
   absence.

## 5. Launcher icon spec (Android)

Generated by `scripts/branding/mark` — regenerate with:

```bash
python3 scripts/branding/make_icons.py   # from the repo root
```

| Layer | Spec |
| --- | --- |
| Adaptive background | Solid Aegis Black `#070707`, 108dp grid (108/162/216/324/432 px) |
| Adaptive foreground | White mark fitted to **62/108** viewport units (inside the 66dp safe circle), centered; shipped both as traced VectorDrawable (`mipmap-nodpi/layered_app_icon_foreground.xml`) and composed bitmap (`mipmap-*/layered_app_icon.png`, mark at 58% of canvas) |
| Legacy icon | Full-bleed Aegis Black square, white mark at 68% of canvas (48/72/96/144/192 px) |
| Monochrome (Android 13 themed) | Same mark, 34/90 viewport units, alpha-only vector |
| Fidelity gate | The tracing script asserts IoU ≥ 0.97 between the vector and the master mark (current: **0.989**) |

How it reaches the APK: the branding hook (`aegis/branding/apply.sh`)
overwrites Chromium's own launcher assets in
`chrome/android/java/res_chromium_base/` with same-name files — verified
against Chromium `156.0.8078.79`. If upstream renames the resources, the hook
skips the copy and says so instead of failing the build.
